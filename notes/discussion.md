## 6. 你提供的技术内容（按章节累积）

### 6.1 Introduction：控制算法回顾与局限性

你给出的要点（会话 6）：
1. 控制论几十年发展迅猛，工业中大规模使用的算法以 PID、LQR、MPC 为代表。
2. PID：无模型控制的代表，算力消耗很低，可运行在单片机上；但积分反馈累加历史信息，历史中混入噪声可能导致之后一段时间窗口内的控制信号震荡失稳；不具备预测能力，难以在剧烈变化中保持跟踪。
3. LQR：基于模型，需要求解 Riccati 方程，算力需求明显高于 PID；标准 LQR 无法实现控制量约束；其他问题由我补充。
4. MPC：在剧烈变化的非线性系统中效果好，支持约束；但算力远高于 LQR，需要稀疏矩阵分解，难以部署到低算力平台。
5. iLQR：LQR 的升级版，近年用于自动驾驶；算力消耗比 LQR 更高。
6. Fradkov 的速度梯度算法（优劣由我补充）；HFC 正是在 SG 的基础上改进得到。
7. Lan 在 "Variational method for finding periodic orbits in a general flow" 中提出用"相空间流"定义代价函数的思想；HFC 正是基于这种代价函数，设计出具备辛结构的 Hamiltonian。

我在写作中补充或调整的内容（都可以删改）：
- PID：把"噪声导致震荡"写成积分项的记忆效应与积分饱和（windup），另加微分项放大噪声；"不具备预测能力"改为"唯一的预测是微分项对误差的线性外推"，因为教科书把微分项解释为线性外推预测，直接说"没有预测能力"会被挑错。
- LQR 补充的局限：只在工作点附近局部有效（做不了起摆这类大范围动作）；加入约束后变成需要多参数规划求解的分段仿射律；权重矩阵与时域指标关系间接；鲁棒裕度只在全状态反馈下成立，加观测器（LQG）后无保证。另外把"实时求解 Riccati 方程"写得更准确：线性时不变调节问题可离线求解一次，非线性、大范围运行或跟踪时变参考时才需要沿轨迹在线求解或做增益调度。
- MPC：补充显式 MPC（离线计算，但分区数随问题规模迅速增长）和稳定性依赖终端代价/约束的设计。
- iLQR：补充其与 DDP 的关系、约束需要专门扩展、可能陷入局部解，并引用 Tassa 等（2012）的实测数据：人形机器人的在线轨迹优化仍比实时慢约 7 倍。
- 新增一段"结构化非线性设计"（反馈线性化、backstepping、滑模、无源性控制）：理论保证强，但依赖模型结构、因系统而异，工业影响远低于 PID 与 MPC。ND 的审稿人大概率会问到这类方法。
- 新增"研究空白"段：PID 计算量极低但不用模型、不能预测；LQR、iLQR、MPC 用模型但计算量逐级升高；缺少的是既能利用非线性模型预测、单步计算量又低、并有收敛保证的控制器。

### 6.2 Formulation：方法本体
- Hamiltonian 的来源与结构（会话 2，原话）："我的 Hamiltonian 是一个从辛算法推广得到的代价函数/能量函数，它应该具有一定的辛几何结构。但这部分需要后续论证确认。"
- 辛结构的具体来源（会话 3）：代价函数中使用了辛 Euler 公式。与代码一致：代价建立在时域 τ 上的一步预测之上，该预测按辛 Euler 的顺序推进。你认为该代价函数可能还有其他辛特性，留待后续细化。
- **算法（会话 7，你的讲解）：**
  1. Lan & Cvitanović 的代价 (λv − ṽ)²：v 为动力系统给出的相空间流速度，ṽ 为参考点与当前点之差给出的几何尺度向量，λ 为尺度缩放因子；该代价在其变分算法中指数递减。
  2. HFC 的能量代价函数 F(𝐱, 𝐮, τ) = ‖Γ(𝐯(𝐱, 𝐮) − (𝐱_ref − 𝐱)/τ)‖²，𝐱 为状态，𝐮 为控制量，τ 为预瞄时间，Γ 为无量纲化矩阵；从 Γ 中提出标量 τ 后写成 F = ‖Γ(τ𝐯(𝐱, 𝐮) − (𝐱_ref − 𝐱))‖²。
  3. 求 F 对 𝐮 各分量的偏导数，乘以量纲配平系数作为 𝐮 的变化率；系统扩展为 {𝐱̇, 𝐮̇}，用 Euler、辛 Euler 或 Runge–Kutta 积分得到 𝐮。
  4. 最大亮点：𝐯(𝐱, 𝐮) 中只有"高阶"状态分量显式含 𝐮，直接求梯度时"低阶"分量的贡献会消失；因此用辛 Euler 改造 𝐯：低阶状态计算相流时，要计入高一阶导函数的变化。低阶记作 q、高阶记作 p，但 q、p 不一定互为共轭变量，只是沿用习惯记号。
- **核实结果（会话 7）：**
  - Lan & Cvitanović（2004，arXiv:nlin/0308008）：流 ẋ = v(x)；环路切向量 ṽ = dx̃/ds；局部时间缩放因子 λ = Δt/Δs（式 4）；离散代价是一步流映射像与下一个环路点之差的平方和（式 8），正对应"参考点减当前点"；Newton descent PDE（式 10）可改写为 ∂_τ(ṽ − λv) = −(ṽ − λv)（式 11），故 ṽ − λv = e^{−τ}(ṽ − λv)|_{τ=0}（式 12），代价 F² = (1/2π)∮(ṽ − λv)² ds（式 13）单调（按 e^{−2τ}）下降。注意这里的 τ 是虚拟时间（fictitious time），与 HFC 的预瞄时间 τ 同名，正文中描述 Lan 的方法时要换符号或只用文字。第 III 节把方法推广到高阶导数系统：匹配最高阶导数 x̃^{(m)} 与 λ^m x^{(m)}（式 14–16），这与 HFC 的"低阶状态计入高阶变化"在思想上一致，可作为辛 Euler 分级的另一层动机。
  - 两份代码与你的描述一致，另有以下实现细节，Formulation 需要交代或说明取舍：
    - 自行车：状态 (x, y, ψ, δ, u)，控制量 (a, ω)；代价 J = w0(Rx/L)² + w1(Ry/L)² + w2 Rψ² + w3 Rδ² + w4(τRu/L)²，即 Γ = diag(√w0/L, √w1/L, √w2, √w3, √w4 τ/L)，权重为纯数。

- **我推导并数值验证的关系（会话 7，待你确认是否写入）：** 取 Q = ½‖Γ(𝐱 − 𝐱_ref)‖²，则 F/2 = Q(𝐱 + τ𝐯) = Q + τω + τ²K，其中 ω = ∇Q·𝐯 是 SG 意义下的"速度"，K = ½‖Γ𝐯‖²。于是前向 Euler 预瞄下 ∇_𝐮F = 2τ∇_𝐮ω + 2τ²∇_𝐮K（精确成立）：τ → 0 时 HFC 的梯度方向就是 SG 的梯度方向（增益矩阵不同）。改用辛 Euler 分级后，低阶误差在 O(τ²) 项中进入梯度：∇_𝐮F = 2τ∇_𝐮ω + 2τ²[(∂𝐚/∂𝐮)ᵀW_q 𝐞_q + ∇_𝐮K] + O(τ³)，其中 W_q 为低阶分量的权重、𝐞_q 为低阶误差。结论已用随机非线性二阶系统的有限差分数值核对（Formulation 中将给出解析证明）。

- **R2 拓扑障碍。** 摆角位于 S¹，四旋翼姿态位于 SO(3)。在这类不同胚于 ℝⁿ 的状态空间上，任何连续反馈都不能使平衡点全局渐近稳定（Bhat & Bernstein, 2000）。收敛定理要么写成局部、区域或几乎全局，要么在角度取值于 ℝ 的覆盖空间上表述，并讨论 unwinding 现象。
  - 四旋翼（会话 3 确认姿态在 SO(3) 上完整描述）：基于连续反馈的几何控制通常只能得到几乎全局的结论（例如 Lee、Leok 与 McClamroch 2010 年在 SE(3) 上的几何跟踪控制）；要做到全局，需要混杂（hybrid）反馈（例如 Mayhew、Sanfelice 与 Teel 2011 年基于四元数的混杂控制）。
  - 把控制量也作为状态并不改变上述结论，因为扩展后的状态空间仍然包含 S¹ 或 SO(3)。
  - SO(3) 上姿态误差函数的选取要注意：例如常用的 Ψ = ½ tr(I − R_dᵀR) 除目标外还有三个临界点（绕主轴转 π），它们会成为闭环的额外平衡点。
- **R3 非完整约束与轨迹跟踪。** 自行车模型做轨迹跟踪，不受 Brockett 条件阻碍（Brockett, 1983，该条件只针对定点镇定）。但这类结论通常要求参考轨迹满足持续激励类条件，例如参考速度不趋于零；若参考轨迹最终停下，问题退化为位姿镇定，障碍重新出现。此外，参考轨迹本身必须满足模型约束（曲率、转向角、加速度界）才可跟踪。这些条件应写进定理的假设。
- **R4 欠驱动。** 小车倒立双摆（3 个自由度、1 个输入）和四旋翼（6 个自由度、4 个输入）都是欠驱动系统。若声称"同一控制律同时完成起摆与稳定"或"无需内外环分层"，论证需要格外严谨。
  - 倒立双摆（会话 3 确认包括起摆）：状态空间 ℝ × T² × ℝ³ 不可缩，连续反馈不可能使倒立点全局渐近稳定（R2）。闭环除倒立点外还可能有其他平衡点，例如静止下垂等构型。要得到"几乎全局"的结论，需要证明所有轨迹都收敛到平衡点集合，并且其他平衡点都不稳定、其吸引集测度为零；做不到的话，就给出倒立点的局部稳定性证明，起摆则由仿真与实验支撑。小车轨道长度与输入约束也要处理。
  - 代表性对比文献：Graichen、Treuer 与 Zeitz（2007）用前馈加反馈完成了小车二级倒立摆的起摆，并有实验验证。
  - 控制输入为作用在小车上的力（会话 5，取代会话 4 的加速度输入）。被控对象是完整的欠驱动 Euler–Lagrange 系统 M(q)q̈ + C(q, q̇)q̇ + G(q) = BF，其中 B = (1, 0, 0)ᵀ，不再依赖"底层伺服能跟踪加速度指令"的假设。代价是小车质量、摩擦与电机/传动特性都进入模型，参数辨识和对摩擦等未建模因素的鲁棒性更为重要。实物实验要说明力如何施加与标定（例如电机电流控制，再按力矩常数和传动比换算），以及摩擦是建模还是补偿。
